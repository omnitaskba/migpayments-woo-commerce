# Available  CSS ids and clasess
Written in format #id/.class (html element) - description

## Checkout Page

    .payment_method_migpaymentspayments(div)- Checkout crypto estimate & currency select wrapper

    #wc-migpayments-payment-method-description(div) - Checkout Migpayments method description

    #wc-migpayments-crypto-estimate-wrapper(div) - Crypto estimates wrapper

    .wc-migpayments-crypto-estimate-item(div) - single crypto estimate item (i.e. 0.01017949 ETH)

    #wc-migpayments-crypto-currency-select-label(label) - Label for Choose  crypto currency select

    #wc-migpayments-crypto-currency-select(select) - Select for crypto  currencies
